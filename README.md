A small Python program that writes a single passive-aggressive note from a smart fridge to its owner: opened fourteen times in one day, nothing taken, and the fridge dryly noting that it too enjoys being looked at like an answer.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the entry text exactly to `/output/entry.txt`, printing nothing else.
